# Discovery Now

Discover the devices on your own home network, keep an inventory of them, and watch
them go online and offline over time.

Two ways to run it:

- **CLI** — a Python library with a command-line interface, for scripts and servers.
- **Desktop app** — a windowed application for Windows and Linux.

> **Status: early development.** Nothing is implemented yet; the feature set is still
> being defined.

## Scope and intended use

Discovery Now is meant for networks you own or are authorized to assess. It is a
discovery and inventory tool, not an exploitation tool: it identifies hosts and the
services they expose, and it never attempts to authenticate, brute-force or exploit
anything.
